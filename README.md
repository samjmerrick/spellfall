# Spellfall

A single-player, portrait-mode card battler for phones: an open board where you choose every attack's target, spell
speeds, priority and a stack that lets the opponent answer on either turn, and five colour factions. Installable,
offline-capable web app.

Forked from Lanefall, a 3-lane simultaneous-reveal game. Until milestone V2 the build still plays Lanefall's rules.

See [`docs/spec.md`](docs/spec.md) for the full design and milestone plan, and [`CLAUDE.md`](CLAUDE.md) for commands.

```bash
pnpm install
pnpm dev
```
